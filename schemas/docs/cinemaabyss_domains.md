Пользователь может
  - зарегестрироваться
  - управлять своим аккаунтом

  - офомить подписку
  - оплатить подписку

  - искать фильмы
  - просматривать инфо о фильмах
  - делать подборку избранное
  - просматривать рекомендации фильмов
  - смотреть фильмы
  - оценивать фильмы

  - может заходить с разных усройств на которые нужна разная инфа


Система
  - подключать другие кинотеатры
  - делать скидки
  - стримить видео из онлайн кинотеатров
  - делать рекомендации на основе данных из сторонней системы


Домен: управление пользователями
  - регистрация
  - редактирование

Домен: кинотеатр
  Поддомен: библиотека фильмов
    - поиск фильмов
    - оценка фильмов
    - рекомендации
    - подборки (пользовательские, редакционные, рекомендательные)

  Поддомен: стриминг
    - просмотр
    - история просмотров
    - подключение кинотеатров
    - стриминг из кинотеатра/встраивание чужого плеера

Домен управления подписками
  - разные типы подписок
  - цены на подписки
  - покупка подписок
  - скидки
  - обработка платежей за подписки

Домен: платежи
  - взаимодействует с сервисом платежей

Домен: рекомендации
  - взамодействие с сервисом рекомендаций
